UserRoleLast sign-inActions
  • Viewer sees every page except Requests.
  • Editor also records actions, undoes, edits spools and products, adds spools by hand, resolves review items, and sees every print request and can change its priority.
  • Admin also manages users, scanners, printers, machine tokens and settings.
  • Requester goes with any role: submits print requests and can edit them while they're Submitted. A Viewer who is a Requester sees only their own requests, and keeps read-only access to them if Requester is turned off.
